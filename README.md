# Customer Success AI Briefing Agent

An AI-powered Customer Success briefing generator built in n8n.

This workflow automatically researches a customer before a meeting, analyses public information using GPT-5, and generates an executive-quality strategic briefing.

## Features

- Company research using Tavily Search
- Executive briefing generation using GPT-5
- AI transformation opportunities
- Customer Success recommendations
- Discovery questions
- Business risks
- Source attribution
- Export-ready output

## Workflow

Form Submission

↓

Tavily Research

↓

Source Formatter

↓

GPT-5 Strategic Analysis

↓

Executive Briefing

## Technology

- n8n
- OpenAI GPT-5
- Tavily Search API
- JavaScript
